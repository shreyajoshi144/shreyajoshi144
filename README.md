## Featured Projects

### Atlas AI — Agentic Research Workspace
[GitHub](https://github.com/shreyajoshi144/atlas)
A 9-stage multi-agent LangGraph pipeline covering search, source ranking, scraping, evidence merging, claim verification, and report generation. Source ranking combines BM25, cosine similarity, fuzzy matching, and credibility scoring to filter evidence quality before generation. Includes a ChromaDB-based semantic memory layer for cross-case retrieval and context-aware follow-up Q&A.
`LangGraph` `LangChain` `ChromaDB` `Groq / Llama 3.3`

### Valora — Hybrid Movie Recommendation Engine
[GitHub](https://github.com/shreyajoshi144/valora-movie-recommendation-engine) · [Live Demo](https://valora-movies.streamlit.app/)
A hybrid recommender combining content-based filtering (TF-IDF + cosine similarity), item-item collaborative filtering, and matrix factorization (Truncated SVD), with dynamic weighting based on user interaction history. Evaluated using a leakage-free, per-user chronological train/test split across 6 strategies, benchmarked on Precision@K, Recall@K, Hit Rate, and RMSE. Includes cold-start fallback and popularity-bias mitigation.
`scikit-learn` `Matrix Factorization` `Streamlit`

### Notiv — Voice-to-Insight Meeting Intelligence
[GitHub](https://github.com/shreyajoshi144/notiv)
An audio-to-insight pipeline transcribing English (Whisper) and Hinglish (Sarvam AI) recordings, with map-reduce summarization and structured action-item and decision extraction via LangChain. Includes a RAG-based chat interface over meeting transcripts using ChromaDB and sentence-transformer embeddings.
`Whisper` `LangChain` `ChromaDB`

### QuerySure — Trust-First Natural Language to SQL
[GitHub](https://github.com/shreyajoshi144/querysure)
A natural-language analytics pipeline that validates generated SQL against the real schema and scores result reliability before producing business insights, designed to catch hallucinated joins and columns before they reach a decision-maker.
`FastAPI` `TF-IDF Retrieval` `SQL Validation`

### Verdict — AI Shopping Intelligence Platform

A multi-retailer shopping comparison platform with LLM-generated buying verdicts, side-by-side comparisons, and a budget planner, secured with JWT authentication.
